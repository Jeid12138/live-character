## 视觉方向

轻量创作工作台：角色预览是主要画面，设置是安静的工具侧栏。延续 LC 青绿色标识，以浅灰绿底色、细边框、统一线图标、明确的主操作和紧凑表单改善层级；设置七分类和分栏调整方式保留。DSH 内嵌与本地调试页同步，桌面工具按钮维持简约白色风格。

参考 Refero 的 Linear Settings 公开索引、Linear/Raycast Styles 与 Raycast 官方设置资料；检索 frontend-design / UI/UX Pro Max 的开发设计规范。完整来源和采用范围见 docs/DESIGN.md。没有复制受限案例截图、下载他人字体或安装新的角色 skill。

## 配置范围

导入/导出位于“设置 → 配置备份”。沿用既有协议：角色的既有设置、语音服务配置（无 Key）、气泡/余额设置、当前模型参数锁定/演出/跟踪/呼吸、触摸校准、独立口型映射及原历史归属处理等。

模型贴图/moc3、Cubism Core、运行依赖及 API Key 不包含在 JSON 里。保留原不同皮套/不同角色配置保护，不把导入配置解释为强制迁移角色或重新分配历史。本轮未扩展全局权限/AI 总开关等原格式外的导入字段。

## 验证

回归套件包含 141 项 Node 与 25 项 Python，最终包的执行结果及哈希写在外附 feedback。新增四项覆盖：

1. 用真实 petPanel 控件事件调整强度/偏移，完整重建页面后读取原值，强度 0 也保留；不写凭据或调用合成。
2. 本机写失败时明确提示，内存不冒充保存成功。
3. 导入/导出仅在设置页出现，宿主镜像仍能读取和触发原控件；原生文件输入入口保留。
4. 实际导出 Blob JSON 包含角色/profile、嘴型强度、触摸、独立口型、呼吸与设置，排除输入框里的密钥。

另用真实 React/React DOM 和实际 client.js，在 JSDOM 中检查七分类、选中语义、配置备份、语音主按钮元信息；这不等于像素级视觉验收。React/编译器仅供开发检查与独立预览，不加入插件运行依赖。

本环境浏览器无法访问本地预览服务，打开本地文件时显示组织策略限制，故未完成浏览器截图/真实窗口的像素级核对，没有绕过限制。真实 Windows DSH/GPU、各主题、缩放与不同尺寸仍需本机复测。包内既有演出/依赖回归继续保留，不把 JSDOM 当作真实 Windows 验收。
