## 时间轴规则

1. 优先 actions:[{kind:"motion"|"gesture",name,at?,seconds?,on?,persistent?}]。最多 12 项，显式 at 0–60 秒，显式 seconds 大于 0 且不超过 20 秒，整个离散序列最多 60 秒。
2. 当 actions 已存在，它是唯一离散动作来源；重复旧 motion/gestures 不执行并给出提示。仅有旧字段时，按 motion → gestures 顺序执行；缺省 at 不再等于全 0。
3. 按数组叙事顺序排期。显式时间落在前项窗口内时向后顺延，给 simultaneous-discrete-actions/overlapping-discrete-actions；乱序给 nonmonotonic-action-time。非法或越界项跳过且有诊断，不伪造新能力。
4. motion 使用原生长度，较长 seconds 可保留其后的排期间隔，但不重复/拉伸动作；配对手势窗口包含进入、保持、返回及淡出，短于原生进入+返回时自动延长并给 action-native-duration。
5. persistent 手势只适合最后一段保持到本轮结束；后面还有动作则降为分段返回并提示。明确 persistent 配饰表情仍可跨轮保留。
6. expressions 仍是可同时叠加的表情层，原先同参数冲突策略保留；pose/fine/keyframes 是独立参数层。keyframes.at 仍是原 plan.duration 内 0–1 进度，绝不是 actions.at 的秒。
7. 原 plan.duration 仍是 0.5–15 秒，保持原关键帧速度；动作总长超出它时只延长本地演出到 actionEnd，不改写关键帧时间比例。

以下为格式示意，名称只代表当前模型确实存在的动作，并非新增内置能力：

```json
{
  "text":"我按顺序做给你看。",
  "emotion":"期待展示给你看",
  "activity":0.6,
  "duration":4,
  "actions":[
    {"kind":"motion","name":"wave","at":0,"seconds":1.2},
    {"kind":"motion","name":"nod","at":1.2,"seconds":1.1},
    {"kind":"motion","name":"bow","at":2.3,"seconds":1}
  ]
}
```

真实模型若某段原生动画更长，后项会相应顺延，不能保证把任意原生动作强塞在示例时间内。

## 语音关系与取消策略

- 动作从本轮音频实际开始时起算，用 currentTime 推进，不用合成请求时间或相邻请求时间差。无语音使用本地单调时钟。
- 音频长于动作：动作各演一次，pose/fine 保持到语音结束，沿用 .33 的实际音频时长机制。
- 音频短于动作：自然 ended 后保留待播动作，以结束时的音频位置为锚继续本地演完，不额外朗读、不压缩原生动作。气泡仍按既定语音/阅读逻辑结束，不为剩余动作重播台词。
- 显式 pause、Stop、静音、手动接管或新回复替换：清空未执行动作。播放恢复不会补播旧动作。自然播放结束自带的 pause 事件按 ended 状态区分，避免错误取消尾段。
- 卡顿或向前 seek 已经越过的动作不会挤到同一帧补播；向后 seek 不重放已经派发的动作。时长/排期记录是采用的计划，不是逐帧完成证明。

这是动作顺序与音频时钟同步，不是台词词级强制对齐；没有声学对齐器或服务商词时间戳时，不宣称精确对应每个“先/然后”的发音位置。
